# AR Playground — «Выдохи в воду»

Независимый статический прототип WebAR на MindAR. Камера распознаёт карточку и открывает семь этапов с упражнениями из интерактивной карты методики.

## Локальный просмотр

Раздайте папку `dist` любым локальным HTTP-сервером. Без HTTPS камера работает только на `localhost`; для проверки на смартфоне нужна HTTPS-публикация.

Страница `print-card.html` предназначена для печати мишени. Кнопка «Посмотреть без карточки» позволяет проверить интерфейс материалов без камеры.
